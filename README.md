## 🛠️ Tecnologías que hacen esto posible
Para lograr la estética sobria, responsiva y las funcionalidades de navegación, el proyecto utiliza:
- **Core:** [React.js](https://reactjs.org/) (v18.2.0)
- **UI Framework Principal:** [Material UI (MUI v5)](https://mui.com/)
- **Componentes Dinámicos:** React Router DOM (v5)
- **Iconografía Completa:** React Icons
- **Despliegue Continuo (CI/CD):** Acciones automáticas programadas mediante GitHub Actions para su publicación en GitHub Pages.

## 💻 Cómo ejecutarlo en entorno local (Modo Desarrollo)

Si deseas inspeccionar el código o probar las modificaciones en tu propia máquina de manera local, sigue estas simples instrucciones:

1. **Clona este repositorio** o descarga el código fuente comprimido.
2. Asegúrate de tener instalado en tu equipo **Node.js** (versión recomendada v16 o superior).
3. Abre tu terminal de preferencia y navega hacia la carpeta raíz del proyecto.
4. **Instala las dependencias** esenciales necesarias ejecutando el siguiente comando:
   ```bash
   npm install
   ```
   *(Nota: si existen advertencias o conflictos heredados de paquetes de tipografías/MUI por versiones modernas de NPM, puedes utilizar `npm install --legacy-peer-deps`)*
5. **Arranca el servidor web local:**
   ```bash
   npm start
   ```
6. Abre tu navegador de preferencia y ve a [http://localhost:3000/#/developer](http://localhost:3000/#/developer) para interactuar con la aplicación reaccionando en vivo a cualquier guardado de código.
